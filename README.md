# original12 optimisation - MLP surrogate

MLP-surrogate optimisation of the same 12 branches and problems as the AVL repository, with the trained normal/duck models included in models/. RUN_ALL_CASES.bat runs the paired MTOW and q_T runs, the altitude-bound sensitivity run and the extra seeds (12 threads, greenlet population batching, checkpoint/resume). See README.txt for details.
